Podstawy i Interfejs
Pierwsze logowanie, architektura urządzenia, backup, aktualizacja firmware, konfiguracja interfejsów LAN/WAN i serwer DHCP. Fundament pod wszystko co dalej.
⏱ 1–2 tygodnie • priorytet: START
Architektura i dostęp
✓
Jak działa FortiGate – architektura ASIC (SoC4, SP5)
TEORIA
▾
FortiGate to Next-Generation Firewall (NGFW) wyposażony we własne układy ASIC (Application-Specific Integrated Circuit). Model 60F ma układ SoC4 (zintegrowane NP6XLite i CP9XLite), a nowszy 120G — układ SP5 – dzięki temu część ruchu jest przetwarzana sprzętowo, a nie przez CPU, co daje gigabitowe przepustowości bez zauważalnego obciążenia procesora.
Kluczowe pojęcia
FortiOS – system operacyjny FortiGate (aktualna gałąź: 7.4.x / 7.6.x)
NP (Network Processor) – sprzętowe przyspieszenie: firewall, IPsec VPN, routing. Duże modele mają osobne NP7, małe mają go wbudowanego w SoC/SP
CP (Content Processor) – przyspiesza SSL/TLS inspekcję, antywirus, IPS (w 60F jako CP9XLite w SoC4, w 120G wbudowany w SP5)
SPU – Security Processing Unit: wspólna nazwa procesorów Fortinet (NP, CP, SoC, SP)
FortiGuard – chmura Fortinet dostarczająca sygnatury AV, IPS, URL filtering, aktualizowane co kilkanaście minut
ℹ️
60F vs 120G
60F: 10 portów GE RJ45, SoC4, firewall do ~10 Gbps — dobry dla małego biura. 120G: SP5, 16 portów GE RJ45 + 8 SFP + 4 SFP+, firewall do 39 Gbps, ochrona przed zagrożeniami ~2,8 Gbps, inspekcja SSL ~3 Gbps (wg karty katalogowej) — rozsądny wybór dla firmy ~100–150 osób. Liczby „na ilu userów” traktuj orientacyjnie: decyduje ruch i włączone profile, nie liczba osób.
✓
Pierwsze logowanie – GUI i CLI
GUICLISTART
▾
FortiGate fabrycznie ma adres 192.168.1.99 na porcie mgmt (lub internal1 zależnie od modelu). Podłącz komputer kablem do tego portu i otwórz przeglądarkę.
Otwórz https://192.168.1.99 (HTTPS! – zaakceptuj self-signed cert)
Login: admin | Hasło: puste (tylko Enter)
System wymusi zmianę hasła przy pierwszym logowaniu – ustaw silne hasło (min. 12 znaków, litery + cyfry + znaki specjalne)
Zapoznaj się z układem: pasek górny (profil, powiadomienia), lewe menu (Network, Policy, Security...), dashboard w centrum
Dostęp przez CLI (SSH lub kabel konsolowy)
# SSH (po skonfigurowaniu sieci)
ssh admin@192.168.1.99

# Kabel konsolowy: 9600 baud, 8N1, bez flow control
# W PuTTY: Connection Type = Serial, Speed = 9600

# Pierwsza komenda diagnostyczna – sprawdź wersję
get system status

# Pokaż wszystkie interfejsy
get system interface physical
⚠️
Zarządzanie przez WAN
Nigdy nie zostawiaj włączonego dostępu HTTPS/SSH na interfejsie WAN w produkcji! System → Network → Interfaces → wan1 → odznacz HTTPS i SSH. Zarządzaj tylko z sieci LAN lub przez dedykowany port mgmt.
✓
Backup i restore konfiguracji – rutyna admina
GUICLIWAŻNE
▾
Backup to Twoje ubezpieczenie. Rób go przed każdą zmianą i przechowuj poza urządzeniem (USB, serwer plików, chmura). Plik .conf to zwykły tekst – możesz go otworzyć notatnikiem i przejrzeć całą konfigurację.
GUI backup: System → Configuration → Backup → wybierz "Local PC" → zapisz plik .conf
Opcjonalnie: zaszyfruj backup hasłem (pole "Encrypt configuration file") – ważne jeśli backup zawiera hasła VPN, PSK itp.
Restore: System → Configuration → Restore → wgraj plik → FortiGate zrestartuje się i wczyta konfigurację
Po restore sprawdź: get system status i przetestuj dostęp do internetu
Backup przez CLI (SCP na serwer)
# Backup na serwer FTP/SCP
execute backup config sftp backup.conf 192.168.1.10 admin haslo

# Backup na USB (jeśli podłączony)
execute backup config usb backup_$(date).conf

# Sprawdź aktualną konfigurację (wylistuj)
show full-configuration | grep -i hostname
✅
Dobra praktyka
Zapisuj backupy z datą w nazwie: FW-FIRMA_2025-01-15.conf. Trzymaj przynajmniej 3 ostatnie wersje. Raz w miesiącu przetestuj restore na środowisku testowym lub laboratoryjnym (FortiGate VM jest bezpłatny do pobrania).
✓
Aktualizacja FortiOS – kiedy i jak
GUIWAŻNE
▾
Fortinet regularnie wydaje aktualizacje bezpieczeństwa. Ważne: nie aktualizuj automatycznie w produkcji. Czytaj Release Notes, testuj na VM lub poza godzinami pracy.
Numery wersji FortiOS
Format: 7.4.3 build 2573 – major.minor.patch build
Gałąź 7.4.x – stabilna, rekomendowana dla środowisk produkcyjnych
Gałąź 7.6.x – najnowsza, może mieć więcej bugów w pierwszych patchach
Fortinet oznacza wersje: ● GA (General Availability) | ● MR (Maintenance Release)
Zrób backup konfiguracji przed aktualizacją!
System → Firmware → sprawdź dostępne wersje (kliknij "Check for Updates")
Przeczytaj Release Notes na docs.fortinet.com – szukaj sekcji "Known Issues" i "Upgrade Path"
Jeśli aktualizujesz przez kilka gałęzi (np. 7.2 → 7.4), przejdź przez pośrednie wersje zgodnie z Upgrade Path
Kliknij "Upgrade" → FortiGate pobierze firmware i zrestartuje się (~5 min)
Po restarcie: sprawdź status, przetestuj polityki i VoIP
🚨
Uwaga na Upgrade Path
Nie można przeskoczyć zbyt wielu wersji naraz. Zawsze sprawdź Upgrade Path Tool na support.fortinet.com. Np. z 7.0 → 7.4 musisz przez 7.2. Pominięcie grozi uszkodzeniem konfiguracji.
⚠️
FortiOS 7.6.3+ i SSL VPN
Od FortiOS 7.6.3 Fortinet usunął tryb tunelowy SSL VPN — zastępuje go IPsec VPN (FortiClient). Jeśli użytkownicy łączą się zdalnie przez SSL VPN, najpierw przygotuj i przetestuj IPsec, dopiero potem aktualizuj do 7.6.3 lub nowszej. Szczegóły w dokumentacji Fortinet: „SSL VPN tunnel mode to IPsec VPN migration”.
Interfejsy sieciowe
✓
Konfiguracja interfejsu WAN – połączenie z ISP
GUICLIKLUCZOWE
▾
Interfejs WAN to "wyjście na świat". Zazwyczaj dostarcza go ISP jako DHCP lub statyczny IP. W FortiGate jest to zazwyczaj wan1.
Network → Interfaces → kliknij wan1 → Edit
Jeśli ISP daje DHCP: Addressing Mode = DHCP. FortiGate automatycznie pobierze IP, maskę, bramę i DNS
Jeśli ISP daje statyczny IP: Addressing Mode = Manual → wpisz IP/maskę. W Network → Static Routes → dodaj default route z bramą ISP
Rola interfejsu: ustaw na WAN (ważne dla SD-WAN i polityk)
Administrative Access: odznacz HTTPS, SSH, Ping (bezpieczeństwo!)
Weryfikacja CLI
# Sprawdź stan interfejsów
get system interface physical

# Sprawdź czy masz domyślną trasę
get router info routing-table all

# Ping do bramy ISP (test WAN)
execute ping 8.8.8.8

# Ping ze wskazanego interfejsu
execute ping-options source wan1
execute ping 8.8.8.8
✓
Konfiguracja LAN dla 120 użytkowników
GUIKLUCZOWE
▾
Dla 120 userów + drukarki + VoIP polecam podsieć /23 (510 hostów) lub /22 (1022 hosty) – daje zapas na wzrost i urządzenia IoT.
Dobór podsieci
MaskaPula hostówKiedy używać
/24254Ciasno dla 120 userów + urządzenia
/23510✅ Dobry wybór – duży zapas
/221022Jeśli planujesz VLANy w przyszłości
Przykład: 10.10.0.1/23 = pula 10.10.0.1 – 10.10.1.254
Network → Interfaces → internal (lub lan) → Edit
IP/Network Mask: wpisz np. 10.10.0.1/23
Rola: LAN
Administrative Access: zaznacz HTTPS, SSH, Ping (tylko dla admina)
Przewiń niżej → DHCP Server → Enable → ustaw zakres
CLI – konfiguracja interfejsu LAN
config system interface
  edit "internal"
    set ip 10.10.0.1 255.255.254.0
    set allowaccess https ssh ping
    set role lan
  next
end
✓
Serwer DHCP – zakres, rezerwacje, opcje
GUICLIWAŻNE
▾
FortiGate może być pełnym serwerem DHCP dla Twojej sieci. Dla drukarek i telefonów VoIP koniecznie ustaw rezerwacje MAC→IP – stałe IP upraszcza diagnostykę i tworzenie polityk.
Network → DHCP Server → Edit (pod interfejsem internal)
IP Range Start: 10.10.0.50 | End: 10.10.1.200 (zostawiasz 10.10.0.1-49 na statyczne urządzenia)
Lease Time: 86400 (24h dla stacji roboczych) lub 3600 (1h dla gości)
DNS Server: wpisz IP Twojego Windows DNS (np. 10.10.0.10) lub 8.8.8.8 jako backup
Default Gateway: 10.10.0.1 (adres FortiGate na LAN)
Mac Reservation → dodaj rezerwacje dla drukarek i telefonów VoIP
Rezerwacja DHCP przez CLI
config system dhcp server
  edit 1
    config reserved-address
      edit 1
        set mac AA:BB:CC:DD:EE:01
        set ip 10.10.0.20
        set description "Drukarka-HP-Recepcja"
      next
    end
  next
end

# Sprawdź aktywne dzierżawy DHCP
diagnose sys dhcp server list
✅
Opcja 66/67 dla VoIP
Jeśli Twoje telefony IP pobierają konfigurację z serwera TFTP (np. przy centrali Cisco/Panasonic), możesz ustawić w DHCP Custom Options: Option 66 = adres serwera TFTP, Option 67 = nazwa pliku konfiguracyjnego.
