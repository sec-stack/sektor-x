Logi i widoczność
✓
Logi – typy, konfiguracja i retencja
GUIWAŻNE
▾
Bez logów jesteś ślepy. FortiGate generuje wiele typów logów – skonfiguruj gdzie je przechowywać i ile czasu trzymać.
Typ loguCo rejestrujeGdzie szukać
Forward TrafficKażda sesja firewall (src, dst, port, polityka, akcja, bytes)Log & Report → Forward Traffic
Event LogLogowania adminów, zmiany konfiguracji, VPN eventsLog & Report → Events
Security LogAV hits, IPS detections, Web Filter blocksLog & Report → Security
DHCP LogKto dostał jakie IP i kiedyLog & Report → Events → DHCP
Log & Report → Log Settings → Local → Enable disk logging (logi lokalne – ograniczona retencja ~7-30 dni)
FortiCloud: Log & Report → Log Settings → Cloud Logging → Enable. Darmowy rolling 7-dniowy dostęp przez Fortinet FortiCloud
W każdej polityce firewall: Logging Options → Log Allowed Traffic: All Sessions
Filtry logów: w widoku Forward Traffic używaj filtrów: Source IP, Destination, Policy, Date Range
ℹ️
FortiAnalyzer dla długiej retencji
Dla środowisk z wymogami compliance (RODO, ISO 27001) potrzebujesz długiej retencji logów (90-365 dni). FortiAnalyzer VM (darmowy do 3 GB/dzień) lub FortiCloud Premium to najlepsze opcje.
✓
Dashboard i widżety monitorujące
GUI
▾
Skonfiguruj dashboard żeby jednym rzutem oka widzieć kondycję sieci. Dodaj widżety które mają znaczenie dla Twojego środowiska.
  • System Resources – CPU, Memory, Disk w czasie rzeczywistym. Alarm gdy CPU >80% przez dłuższy czas
  • Interface Bandwidth – wykres ruchu na WAN i LAN. Widać szczyty i anomalie
  • Sessions – liczba aktywnych sesji. Nagły spike sesji = atak lub wirus
  • Top Sources – kto generuje najwięcej ruchu (IP stacji roboczej)
  • Top Destinations – dokąd idzie ruch (podejrzane zewnętrzne IP)
  • Top Applications – jakie aplikacje dominują (po włączeniu App Control)
  • FortiGuard Quota – status licencji i aktualizacji sygnatur
  • HA Status – jeśli masz High Availability (dwa FortiGate)
✓
Alerty email – powiadamiaj się zanim zadzwoni user
GUIWAŻNE
▾
FortiGate może wysyłać alerty email przy krytycznych zdarzeniach. Skonfiguruj to w pierwszym tygodniu – oszczędzisz sobie wielu niespodzianek.
System → Advanced → Email Service → skonfiguruj serwer SMTP (np. smtp.office365.com:587, TLS)
Log & Report → Alert Email → Create New
Adres docelowy: skrzynka IT helpdesk lub Twoja osobista
Triggery do ustawienia: Interface DOWN, High CPU (>90% przez >1 min), Admin Login Failed (>3 razy), VPN Down, Critical AV Detection, License Expiring (30 dni przed)
Testuj: wyślij testowy email z GUI żeby potwierdzić działanie SMTP
✓
Kluczowe komendy CLI do codziennej diagnostyki
CLICHEATSHEET
▾
══ STAN SYSTEMU ══
get system status # wersja, uptime, serial
get system performance status # CPU, pamięć, sesje
diagnose sys top # top procesów (jak Linux top)

══ SIEĆ ══
get system interface physical # stan fizyczny portów
get router info routing-table all # tablica routingu
get system arp # tabela ARP
execute ping 8.8.8.8 # ping z FortiGate
execute traceroute 8.8.8.8 # traceroute

══ SESJE ══
diagnose sys session stat # statystyki sesji
diagnose sys session filter src 10.10.0.55
diagnose sys session list # sesje danego IP

══ DEBUG FLOW (krok po kroku) ══
diagnose debug reset
diagnose debug flow filter addr 10.10.0.55
diagnose debug flow trace start 50
diagnose debug enable
# ... generuj ruch z PC usera ...
diagnose debug disable

══ SNIFFER ══
diagnose sniffer packet wan1 "host 8.8.8.8" 4
diagnose sniffer packet any "port 5060" 4 # VoIP

══ DHCP ══
diagnose sys dhcp server list # aktywne dzierżawy

══ POLITYKI ══
show firewall policy # lista wszystkich polityk
diagnose firewall iprope show 100004 0 # szczegóły tablicy policy

Scenariusze awaryjne – ćwicz zanim się zdarzy
KRYTYCZNE
▾
Awaria FortiGate = 120 userów bez sieci. Im lepiej znasz procedury, tym szybciej przywracasz działanie. Ćwicz te scenariusze w spokojnych warunkach.
  • Factory Reset + Restore z backup: execute factoryreset → po restarcie zaloguj się domyślnie → restore backup → testuj. Czas: ~10 min
  • Zablokowany dostęp do GUI: połącz przez kabel konsolowy → zaloguj się do CLI → sprawdź polityki i interfejsy → przywróć dostęp HTTPS
  • Zapomniane hasło admina: fizyczny dostęp do urządzenia + reset hasła przez konsolę (konto maintainer — trzeba się zalogować w krótkim oknie czasowym po starcie; działa tylko, jeśli nie zostało wyłączone w konfiguracji)
  • Awaria łącza WAN: jeśli masz SD-WAN – automatyczny failover. Bez SD-WAN: ręcznie zmień default route na backup ISP (modem LTE?)
  • Przepełniona pamięć/dysk: diagnose sys top → znajdź pożerający RAM proces → restart usługi lub cały FG. Wyczyść stare logi
  • Aktualizacja poszła źle: FortiGate trzyma poprzednią wersję firmware – w GUI możesz rollback do poprzedniej wersji

Certyfikacja NSE – oficjalna ścieżka Fortinet
CERTYFIKATWARTO
▾
Fortinet Network Security Expert (NSE) to 8-poziomowa ścieżka certyfikacji. Dla admina FortiGate celem głównym jest NSE 4. Kursy i egzaminy dostępne bezpłatnie na training.fortinet.com.

✅
NSE 4 – co obejmuje
FortiOS, Firewall Policies, NAT, Routing, SSL VPN, IPsec VPN, SD-WAN, High Availability, Security Profiles (AV, IPS, WebFilter), Logging & Monitoring. Dokładnie to, czym zarządza admin FortiGate na co dzień. Od lipca 2026 certyfikat nazywa się NSE 4 – FortiOS Administrator (Fortinet wrócił do numeracji NSE 1–8). Aktualny format egzaminu sprawdź na training.fortinet.com.
