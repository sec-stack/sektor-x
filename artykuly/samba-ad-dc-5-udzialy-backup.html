SMB Shares i drukarki
Konfiguracja udziałów działowych w smb.conf
CLIWAŻNE
▾
Udziały SMB to foldery sieciowe dostępne dla użytkowników Windows. Uprawnienia zarządzasz przez grupy AD.
⚠️
Lepiej: udziały na osobnym serwerze
Samba pozwala trzymać udziały na kontrolerze domeny i w małym biurze to działa, ale dokumentacja Samby zaleca osobny serwer plików dołączony do domeny (domain member). Łatwiej go backupować, aktualizować i odtworzyć, a awaria dysku z danymi nie kładzie logowania całej firmy.
# Utwórz foldery na udziały sudo mkdir -p /srv/samba/{IT,Biuro,Wspolny} sudo chmod 0770 /srv/samba/{IT,Biuro,Wspolny} sudo chown root:"FIRMA\IT" /srv/samba/IT sudo chown root:"FIRMA\Biuro" /srv/samba/Biuro sudo chown root:"FIRMA\Domain Users" /srv/samba/Wspolny
# Dodaj udziały do smb.conf sudo nano /etc/samba/smb.conf
# Sekcje do dodania w smb.conf [IT] path = /srv/samba/IT valid users = @"FIRMA\IT" read only = no browseable = yes [Biuro] path = /srv/samba/Biuro valid users = @"FIRMA\Biuro" read only = no browseable = yes [Wspolny] path = /srv/samba/Wspolny valid users = @"FIRMA\Domain Users" read only = no browseable = yes
# Sprawdź poprawność smb.conf i restart sudo testparm sudo systemctl restart samba-ad-dc

⏱ 2–3 godziny • priorytet: WAŻNY
Monitoring i backup
Backup bazy Active Directory
CLIKRYTYCZNE
▾
Baza AD to serce całej infrastruktury — jej utrata oznacza utratę wszystkich kont, grup i polityk. Backup codziennie.
#!/bin/bash # backup-ad.sh — backup Samba AD DC DATE=$(date +%Y-%m-%d) BACKUP_DIR="/backup/samba" mkdir -p $BACKUP_DIR # Backup bazy Samba — tryb offline działa lokalnie jako root i nie pyta o hasło, # więc nadaje się do crona (tryb "online" z -U Administrator zatrzyma się na pytaniu o hasło) samba-tool domain backup offline \ --targetdir=$BACKUP_DIR # Backup smb.conf i krb5.conf cp /etc/samba/smb.conf $BACKUP_DIR/smb.conf.$DATE cp /etc/krb5.conf $BACKUP_DIR/krb5.conf.$DATE # Usuń backupy starsze niż 30 dni find $BACKUP_DIR -mtime +30 -delete echo "Backup AD zakończony: $DATE"
# Dodaj do crona — backup o 2:00 w nocy sudo crontab -e # Dodaj linię: 0 2 * * * /usr/local/bin/backup-ad.sh >> /var/log/backup-ad.log 2>&1
Cheatsheet — komendy diagnostyczne
CLICHEATSHEET
▾
# ── STATUS USŁUG ── sudo systemctl status samba-ad-dc sudo samba-tool domain level show # ── UŻYTKOWNICY ── sudo samba-tool user list sudo samba-tool user show USERNAME sudo samba-tool user setpassword USERNAME --newpassword='Haslo123!' # ── KOMPUTERY ── sudo samba-tool computer list sudo samba-tool computer delete KOMPUTER$ # ── DNS ── sudo samba-tool dns query 127.0.0.1 ad.firma.pl @ ALL host -t SRV _ldap._tcp.ad.firma.pl # ── KERBEROS ── kinit Administrator@AD.FIRMA.PL klist kdestroy # ── LOGI ── sudo journalctl -u samba-ad-dc -f sudo tail -f /var/log/samba/log.samba # ── SAMBA TEST ── sudo samba-tool drs showrepl sudo samba-tool fsmo show
